🔒 File Encryption Tool

A C++ and Qt 6 desktop application that encrypts and decrypts text and binary files with a password, using Caesar Cipher, Vigenère Cipher and AES-128.

C++17Qt 6CMakeOpenSSLAES-128-CBC
  • Password verification with SHA-256
  • AES key derived with PBKDF2-HMAC-SHA256 (100,000 iterations), random salt and IV
  • Simple GUI with file browser, show-password option and status messages
